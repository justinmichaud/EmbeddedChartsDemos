# WasmCharts — a Rust/wasm-first stock-chart engine

A from-scratch, Rust-first reimagining of `JSChartsFast`. The same real-time
stock-ticker demo (live charts updating at 5 Hz, click-to-detail, settings,
news, sweep) — but instead of React + recharts (SVG) fed by a Web Worker, the
**entire chart surface is a single `<canvas>` driven by one Rust/wasm module**.

## Why this shape

The original's cost centers were exactly what JS/SVG are worst at: retained-mode
SVG DOM that React reconciles every tick, plus a worker→main `postMessage`
serialize + `.slice()` deserialize on every update. In an immediate-mode canvas
there's no DOM tree to reconcile, so **React's value proposition disappears**;
with sim + render in one wasm module, the **worker boundary disappears** too —
the data lives once in linear memory and the draw loop reads it directly.

### What's Rust vs. what's JS

| Rust / wasm (`crates/charts`) | JS / HTML (thin host) |
|---|---|
| Price simulation, ring buffers, PRNG (`sim.rs`) | Canvas creation + HiDPI sizing, rAF loop, event forwarding, `localStorage` (`src/host.ts`) |
| Responsive grid layout (`layout.rs`) | Menu bar, FPS, clock, settings `<dialog>`/`<select>`, news strip, CSS sweep (`index.html` + `styles.css`) |
| All chart drawing — lines, areas, grid, axis labels, **and every number** via Canvas2D `fillText` (`draw.rs`) | |
| Y-range hysteresis, hit-testing, view state (`state.rs`, `lib.rs`) | |

Drawing uses **Canvas2D, not WebGL**: at 60 points / 5 Hz the win is leaving
retained-mode SVG for immediate mode, not the GPU — and Canvas2D's native
`fillText` gives crisp text with no glyph atlas and no texture churn.

The whole front end is **~20 kB of JS** (vs. the original React + recharts
bundle) plus a 67 kB wasm module (30 kB gzipped).

## Layout

```
crates/charts/        Rust engine (wasm-bindgen → src/wasm/)
  src/lib.rs          #[wasm_bindgen] Engine: new/resize/frame/pointer_down/...
  src/sim.rs          ring buffers + Xorshift128 PRNG + tick
  src/layout.rs       responsive grid (2/3/4/5/6 cols) → cell rects
  src/draw.rs         per-chart Canvas2D drawing
  src/state.rs        Settings, View, per-chart Y-range cache
src/host.ts           ~120-line host (no framework)
src/wasm/             wasm-pack output (gitignored, regenerated by build)
index.html, src/styles.css   HTML chrome
tests/engine.spec.ts  Playwright tests driving window.__engine
```

## Development

Requires the Rust wasm toolchain:

```
rustup target add wasm32-unknown-unknown
cargo install wasm-pack
```

Then:

```
pnpm install
pnpm dev          # runs `wasm:build` (wasm-pack) then vite
```

`pnpm wasm:build` rebuilds only the Rust crate. `pnpm dev`/`pnpm build` run it
automatically via the `predev`/`prebuild` hooks.

## Production build / memory test

```
pnpm build                  # → dist/ (base /EmbeddedChartsDemos/)
pnpm dlx serve dist         # serve the static build
```

## Tests

```
pnpm test                   # Playwright; covers live-canvas, hit-testing,
                            # scroll growth, news, and a no-leak heap check
```
